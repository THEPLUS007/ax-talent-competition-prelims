# Travel Blocks AI UI / UX Requirements

## 목적

Travel Blocks AI는 단순한 여행 일정 관리 서비스가 아니다.

사용자가 AI가 생성한 여행 블록을 레고처럼 자유롭게 조립하고,
동선을 시각적으로 확인하며,
AI의 도움을 받아 여행을 완성하는 경험을 제공하는 것이 목표이다.

모든 UI는 이 목표를 기준으로 설계한다.

---

# 1. 첫 실행(Onboarding)

앱 실행 시 바로 편집 화면으로 이동하지 않는다.

가장 먼저

"새 여행 만들기"

모달(또는 첫 화면)을 보여준다.

사용자는 아래 3가지 방식 중 하나를 선택한다.

---

## 1-1. 새 여행 직접 생성

큰 버튼 형태로 제공한다.

예시

🧳
새 여행 직접 생성

버튼 클릭 시 아래 입력폼이 펼쳐진다.

입력 항목

- 여행 제목
- 국가
- 도시
- 여행 기간
- 예산
- 인원
- 여행 스타일

생성 버튼

"여행 생성"

생성 후 빈 일정이 만들어진다.

AI는 사용하지 않는다.

---

## 1-2. AI 요청 기반 여행 생성

큰 버튼 형태로 제공한다.

🤖
AI 여행 생성

질문을 여러 번 하는 방식이 아니다.

큰 입력창 하나만 제공한다.

Placeholder 예시

여행 기간, 국가, 도시,
예산, 인원,
여행 스타일 등을 자유롭게 입력해주세요.

예)

커플 여행

렌터카 이용

예산 80만원

카페 많이 가고 싶어요

바다도 보고 싶어요

AI 일정 생성 버튼

↓

---

## Split View

두 개 이상의 Day를 동시에 볼 수 있다.

예)

Day1 | Day2

또는

Day1 | Day2 | Day3

각 Day 사이로 블록 드래그 가능

---

## Detach View

특정 Day를 별도 패널처럼 분리한다.

실제 새 브라우저 창이 아니어도 된다.

모달 또는 드로어 형태도 가능하다.

멀티 모니터 사용자를 고려한 UX를 제공한다.

---

# 4. 여행 블록

여행 블록은 카드가 아니라

조립 가능한 블록처럼 보여야 한다.

각 블록은

- 제목
- 시간
- 비용
- 카테고리
- 드래그 핸들

을 가진다.

드래그하여

순서를 변경할 수 있다.

Day 사이 이동도 가능하다.

---

블록은 연결선으로 이어진다.

↓

↓

관광지

# 6. 검색 결과 → 블록 변환

사용자는

숙소

식당

관광지

항공권

액티비티

를 검색할 수 있다.

검색 결과는 일반 카드 형태이다.

"블록으로 추가"

버튼을 누르면

Travel Block으로 변환된다.

현재 선택한 Day에 추가된다.

---

# 7. AI 추천 블록

추천 블록은

단순한 카드가 아니다.

반드시

추천 이유를 표시한다.

예)

숙소와 10분 거리

현재 예산 내

영상에서 언급된 장소

Day2 동선과 잘 맞음

드래그하여 일정으로 추가 가능해야 한다.

---

# 8. AI 보조

우측 하단

✨ AI

버튼 제공

누르면

사이드 패널이 열린다.

역할

여행 편집 보조

예시

빈 시간 채우기

예산 줄이기

맛집 추천

촬영지 추천

비 오는 날 일정 추천

추천 결과는

"블록으로 추가"

버튼을 제공한다.

---

# 9. 예산 UI

화면 상단에는

총 예산

현재 사용 금액

남은 예산

을 표시한다.

Day별 예상 비용도 함께 표시한다.

추천 블록 추가 시

예산 변화가 즉시 반영된다.

---

# 10. AI 분석 화면

링크 분석 또는 AI 생성 시

단순 완료 메시지를 보여주지 않는다.

진행 과정 UI를 제공한다.

예)

링크 확인

↓

장소 추출

↓

식당 분류

↓

숙소 분류

↓

동선 생성

↓

여행 블록 생성

완료 후

장소 수

블록 수

예상 비용

추천 블록 수

등을 보여준다.

---

# 11. 저장

저장 버튼 클릭 시

현재 여행을 저장한다.

별도

"내 여행"

목록을 제공한다.

여행 클릭

↓

불러오기

가능해야 한다.

---

# 12. 내보내기

블록 일정을

텍스트 일정으로 변환한다.

예)

🌴 제주 2박3일

DAY1

🏨 체크인

🍜 고기국수

🌃 동문시장

DAY2

🌄 성산일출봉

☕

복사 버튼 제공

---

# 13. AI 여행 품질 점수

화면 상단에

AI 여행 점수

카드를 제공한다.

예)

92점

평가 항목

- 동선 효율
- 예산 적합성
- 이동 피로도
- 여행 다양성

블록을 수정하면

점수가 실시간 갱신된다.

AI는

왜 점수가 올랐는지

왜 내려갔는지

설명도 함께 제공한다.

---

# 14. 전체 UX 원칙

Travel Blocks AI는

"예쁜 일정표"

가 아니라

"여행 블록 조립 도구"

처럼 느껴져야 한다.

사용자는

AI가 만든 블록을

드래그

↓

조립

↓

수정

↓

저장

↓

공유

하는 흐름을 자연스럽게 경험할 수 있어야 한다.
