# Travel Blocks AI Functional Specification

## 목적

이 문서는 Travel Blocks AI의 모든 기능을 구현하기 위한 기능 명세서이다.

모든 기능은 MVP 기준으로 구현하며,
실제 API가 없는 기능은 Mock 데이터로 동작해야 한다.

---

# 1. 여행 생성

## 1.1 직접 여행 생성

사용자가 직접 빈 여행을 생성한다.

입력 항목

- 여행 제목
- 국가
- 도시
- 여행 기간
- 예산
- 인원
- 여행 스타일

생성 결과

- 빈 Day 생성
- Day1 자동 생성
- 일정 블록 없음

AI 사용 없음

---

## 1.2 AI 요청 기반 여행 생성

사용자는 자유롭게 여행 정보를 입력한다.

예시

3박4일 제주

커플 여행

렌터카

예산 80만원

카페 많이 가고 싶어요

입력 완료 후

"AI 일정 생성"

버튼을 누른다.

Mock AI는

- 여행 기간 분석
- 도시 분석
- 예산 분석
- 여행 스타일 분석

후

여행 블록을 생성한다.

생성 이후

모든 블록은

추가

삭제

수정

이동

가능해야 한다.

---

## 1.3 링크 / 텍스트 / 영상 분석

입력

- Youtube URL
- 블로그 URL
- 일반 URL
- 여행 일정 텍스트

- 이동수단

이후

여행 블록으로 변환한다.

# 17. 최종 목표

Travel Blocks AI는

단순 일정표가 아니라

AI가 생성한 여행 블록을

사용자가

조립하고

비교하고

수정하고

공유하는

여행 설계 도구가 되어야 한다.

기존 여행 일정 서비스와 차별화되는 핵심은

"여행을 블록 단위로 조립하는 경험"

이다.
