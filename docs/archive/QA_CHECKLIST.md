## 기능별 상세 테스트 시나리오

### TS-01 자연어 AI 여행 생성

1. 첫 화면에서 `AI 여행 생성` 선택
2. NL-01~NL-04 중 하나 입력
3. `AI 일정 생성` 클릭
4. 여행 정보 카드 확인
5. Day 탭 개수와 블록 개수 확인
6. AI 추천 메뉴를 열어 추천 지역 확인

예상 결과:
- 입력 도시와 일치하는 여행 정보가 자동 입력된다.
- Day와 블록이 생성된다.
- 추천 블록은 선택 Day의 `region/city` 기준으로 바뀐다.

### TS-02 URL 분석

1. 첫 화면에서 `영상 / 링크 분석` 선택
2. URL-01~URL-06 중 하나 입력
3. `분석 시작` 클릭
4. 여행 정보, Day, 블록 생성 확인

예상 결과:
- Mock 모드에서는 실제 크롤링 없이도 분석 흐름이 정상 동작한다.
- YouTube/네이버 모바일/네이버 PC/티스토리 URL 모두 입력과 분석 요청이 가능하다.

### TS-03 장소 검색 기반 블록 추가

1. 일정 편집 화면에서 `블록 추가` 클릭
2. 카테고리를 `음식`, `카페`, `관광`, `액티비티` 중 하나로 선택
3. 장소 검색 입력창에 키워드 입력 또는 기본 후보 확인
4. 후보 장소 클릭
5. 제목/위치/비용/메모 자동 입력 확인
6. `적용` 클릭

예상 결과:
- 선택 Day의 `city/region`에 맞는 장소가 우선 표시된다.
- 후보 선택 시 블록 초안이 자동 완성된다.

### TS-04 지도에서 보기

1. 블록 카드의 점 3개 메뉴 클릭
2. `지도에서 보기` 클릭
3. 새 탭에서 Google Maps 검색 링크가 열리는지 확인

예상 결과:
- 장소명/위치 기반 검색 URL이 열린다.

### TS-05 내보내기

1. 일정 편집 화면 헤더 우측 `내보내기` 클릭
2. `클립보드 복사` 클릭
3. 텍스트 편집기에 붙여넣어 일정 텍스트 확인
4. 다시 `내보내기` 클릭
5. `PDF로 저장` 클릭
6. PDF 파일이 바로 다운로드되는지 확인
7. 다운로드된 PDF를 열어 Notion 문서 느낌의 레이아웃 확인
8. `공유용 텍스트 생성` 클릭 후 붙여넣기 확인

예상 결과:
- Day, 블록, 이동 정보가 포함된 PDF 파일이 직접 다운로드된다.
- 공유용 텍스트는 마크업이 제거되어 읽기 쉽다.

### TS-06 저장/불러오기

1. 일정 생성 후 블록 하나 추가 또는 수정
2. `현재 여행 일정 저장` 클릭
3. `?user=user2` 또는 `/user2`로 이동
4. `saved-current-local`에 해당하는 최신 저장 일정이 목록 상단에 표시되는지 확인
5. 카드 클릭 후 편집 화면 로드 확인

예상 결과:
- 저장된 일정이 localStorage에서 복원된다.
